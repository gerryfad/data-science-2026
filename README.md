## Tools & Library yang Digunakan

| Tools / Library | Kegunaan |
|:----------------|:---------|
| **Python 3** | Bahasa pemrograman utama |
| **Pandas** | Manipulasi dan analisis data berbasis DataFrame |
| **NumPy** | Operasi numerik dan array |
| **Matplotlib** | Visualisasi data (grafik batang, histogram, scatter plot) |
| **Seaborn** | Visualisasi data tingkat tinggi (boxplot, heatmap, pairplot) |
| **scikit-learn** | Machine Learning (LinearRegression, StandardScaler, train_test_split, metrik evaluasi) |
| **Google Colab / Jupyter Notebook** | Lingkungan pengembangan interaktif |

## Cara Menjalankan Notebook

1. Buka [Google Colab](https://colab.research.google.com/).
2. Pilih **File** → **Upload notebook**.
3. Unggah file `.ipynb` yang diinginkan.
4. Jalankan sel-sel kode secara berurutan (**Runtime** → **Run all**).
